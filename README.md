## ⚡ 一键同步使用说明

根目录下提供了 **`一键同步.bat`** 自动化批处理脚本：

1. **双击运行**：在 Windows 资源管理器中双击 `一键同步.bat`。
2. **自动化流程**：
   - 先自动执行 `git pull` 拉取 GitHub 远端更新；
   - 自动检测本地是否有修改（无修改则友好提示并退出，避免空提交）；
   - 若有修改，自动暂存并按当前精准时间戳提交（如 `Update: 2026-11-20 15:45:00`）；
   - 推送至 GitHub 远程主分支。
3. **安全机制**：遇到网络异常或推送冲突时，控制台窗口会自动暂停保留错误日志，不会闪退。

## 📌 协作与规范建议

1. **图片相对路径**：
   所有插入的图片统一保存在 `assets/images/` 目录下，在 Markdown 中使用**相对路径**引用（例如 `![示意图](../../assets/images/sample.png)`），确保 GitHub 网页端与本地编辑器均可正常渲染。
2. **模板复用**：
   新写技术总结或日志时，可直接参考 `templates/` 目录下的标准模板。
